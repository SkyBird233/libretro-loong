# Mupen64Plus-Next

Tested games:
- Super Mario 64

## JIT support

Mupen64Plus-Next uses Ari64's in-tree CPU dynamic recompiler. It has x86, x86-64, ARM, and AArch64 backends, but no LoongArch64 backend, so the LoongArch64 build has no JIT.
